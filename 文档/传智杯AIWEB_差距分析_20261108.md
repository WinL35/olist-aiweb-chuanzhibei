## 三、三个结构性错位（比缺功能更值钱，要摆在文档第一页回答）

### 错位 1：赛道要「前端为主」，项目是「后端为主」

官方原文：

> 参赛作品须以**前端 Web 应用为主要呈现形态**，后端服务仅作为 AI 能力的接入层，**不作为重点考察对象**。

本仓库实测：`py 11,718 行` vs `js 950 + html 458 + css 371 = 1,779 行`（其中 vendor 14 行不算）→ **13% 前端 / 87% 后端**。

不修这一条，评委的默认印象就是「AI 数据分析后端套了层网页皮」，前端 10% 只拿 3 分是结果，不是原因。

### 错位 2：技术栈不在推荐列表

赛道推荐：React + Next.js 14（首选）/ Vue 3 + Nuxt 3 / React + Vite / SvelteKit / Astro；UI 用 Tailwind + shadcn/ui；AI 交互用 Vercel AI SDK / LangChain.js；状态管理 Pinia/Zustand；SSE/WebSocket 流式。

现状：**FastAPI + 原生 HTML + Vue global build（CDN 版）+ 手写 fetch**。没有 `package.json`、没有构建工具、没有 npm 生态。

> 「技术选型不做强制限定」，但 25% 创新 + 10% 前端工程这两块是主观分，选型离推荐越远，解释成本越高。

### 错位 3：个人赛报名 vs 团队赛要求

AI WEB 是团队赛：1–3 人同校、≤2 名指导教师、README 须含团队信息、决赛有现场答辩（占 30%）。现在材料通篇「个人赛 · 选题 8」，直接投会被判材料不符。

## 五、必须现在就决定的三件事

1. **要不要重写前端？** 只有 10 天。重写（Vite + SFC + TS + 路由，后端不动）约 2.5 天，是投 AI WEB 的必要条件；不重写就别投这个赛道，留在「AI 创新应用」（个人赛）更划算——那边你现有材料已基本齐活，只差推仓库 + 录视频。
2. **要不要组队？** 团队赛；1 人也算队，但决赛有现场答辩（30%），3 人分工（前端 / 算法 / 文档）明显更稳。
3. **要不要双投？** 同一套代码可同时报「AI 创新应用（个人）」和「AI WEB（团队）」，两赛道都 11-18 截止，材料可复用 80%。代价是视频与文档要各出一版口径（个人赛讲「选题 8 数据分析」，团队赛讲「AI Native 前端」）。
