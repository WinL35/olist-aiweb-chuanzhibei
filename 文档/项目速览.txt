================================================================
  Olist 电商经营分析与智能选品平台 — 项目速览
  生成时间：2026-10-22
================================================================

  基于 Olist 巴西电商公开数据（99,441 订单 / 95,420 用户 / 74 品类），
  本地运行的「看数 → 分群 → 预测 → 选品 → 定价」一体化平台。

【规模】
  · 7 个页面、33 个后端接口、2 套算法、21 个 ECharts 图表
  · 业务库 olist_db：13 张表 + 10 个视图，872,359 行
  · 算法库 olist_algo_db：9 张表，结果表 96,462 行（另有同步日志表按次追加）
  · 技术栈：Python 3 / FastAPI / MySQL 8.0 / Vue 3.5 / ECharts 5.6

----------------------------------------------------------------
  一、七个页面各做什么
----------------------------------------------------------------
  经营看板   GMV 1,359 万、客单价 137、支付转化率 99.8%、复购率 3.1%
             趋势 / 品类 / 区域 / 支付 / 评价 共 8 张图
  用户分群   RFM 规则 8 类 + K-Means 4 类
             高价值 2,913 人（3.05%）、流失风险 33,530 人（35.14%）
  转化分析   订单漏斗 99,441 → 99,281 → 97,644 → 96,461 → 95,815
  销量预测   品类未来 1–8 周，含移动平均基线与 95% 区间
  选品建议   规模×增长 Top10；离线对照：热门策略命中 80%，纯增长策略 0%
  定价建议   50 个商品中 31 个可估弹性，平均预期营收 +26.6%
             19 个样本不足，明确显示「数据不足」而非 0
  模型实验   4 模型 MAPE 对照：主模型 135.73% vs 基线 136.89%
             中位数 90.46% vs 99.69%，如实表述为「部分品类优于基线」

----------------------------------------------------------------
  三、全新机器运行顺序
----------------------------------------------------------------
  ① pip install -r requirements.txt
  ② python3 一键导入主库.py
  ③ python3 一键导入算法库.py    （算法库9表+主库10视图，纯Python，不需要mysql命令行）
  ④ python3 启动后端.py
  ⑤ python3 scripts/smoke_test.py      （另开终端）

  浏览器打开 http://127.0.0.1:8000

  【如果想从零重算算法】把下面 5 个文件插在 ③ 之后依次执行：
     pipeline/algo1_model.py
     pipeline/algo2_model.py
     pipeline/import_algo1.py
     pipeline/import_algo2.py
     pipeline/export_algo_to_mysql.py

  【如果想跳过主库导入】把 Olist.sql 一起拷过去，用它替代第②步：
     mysql -uroot -p < Olist.sql   （自带建库建表建视图；没有 mysql 命令行就用 Navicat 运行）
     然后照常执行 ③④⑤（③ 里的视图是 CREATE OR REPLACE，重复执行无害）
