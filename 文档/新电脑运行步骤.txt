Olist 电商经营分析与智能选品平台
新电脑运行步骤（照着做，5 分钟能跑起来）
================================================================

一句话：装好依赖后，按顺序运行 3 个文件，不要颠倒。

  ①  一键导入主库.py
  ②  一键导入算法库.py
  ③  启动后端.py


----------------------------------------------------------------
一、前置准备（只做一次）
----------------------------------------------------------------
需要：Python 3.10 以上、MySQL 8.0 以上，且 MySQL 服务正在运行。

  1) 解压交付包，进入项目根目录（能看到 一键导入主库.py 的那一层）
        cd Olist项目

  2) 安装依赖（约 1 分钟）
        pip install -r requirements.txt


----------------------------------------------------------------
二、按顺序运行这 3 个文件
----------------------------------------------------------------
① 一键导入主库.py
   命令：  python3 一键导入主库.py
   作用：  创建 olist_db，建 13 张业务表，导入 cleaned/*.csv
   耗时：  约 28 秒
   成功：  打印 13 张表的行数，最后一行是
           [成功] 主库导入完成，后端可以连了

② 一键导入算法库.py
   命令：  python3 一键导入算法库.py
   作用：  创建 olist_algo_db（9 张表）+ 主库 10 个视图
   耗时：  约 1 秒
   成功：  打印 9 张表 / 96,462 行 / 10 个视图

③ 启动后端.py
   命令：  python3 启动后端.py
   作用：  启动 Web 服务（8000 端口）
   成功：  先打印
             主库 olist_db: 存在
             算法库 olist_algo_db: 存在
           再打印
             Uvicorn running on http://127.0.0.1:8000

   然后浏览器打开：  http://127.0.0.1:8000

        pip install -r requirements.txt
        python3 一键导入主库.py
        python3 一键导入算法库.py
        python3 启动后端.py

说明：Windows 把 python3 换成 python 即可。
      也可以直接在 PyCharm 里依次 Run 这三个文件。
      三个脚本都会自动问 MySQL 密码，不用先去改配置文件。


----------------------------------------------------------------
三、跑完自检（可选，约 30 秒）
----------------------------------------------------------------
另开一个终端，仍在项目根目录：

        python3 scripts/smoke_test.py

期望看到：
        全部通过：最慢 xxx ms，P95 xxx ms
        性能通过：所有本次核心接口单次响应均不高于 2 秒。


----------------------------------------------------------------
四、这些文件不用跑（避免误操作）
----------------------------------------------------------------
  ×  任何 mysql 命令行            三个脚本都用 pymysql，不需要 mysql 客户端
  ×  pipeline/algo1_model.py      算法结果已随包提供并入库，重跑只为改算法
  ×  pipeline/algo2_model.py      同上
  ×  pipeline/import_algo1.py     已被 ② 一键导入算法库.py 调用
  ×  pipeline/import_algo2.py     同上
  ×  pipeline/export_algo_to_mysql.py  同上
  ×  pipeline/load_mysql.py       已被 ① 一键导入主库.py 调用
  ×  pipeline/clean_merge.py      仅当你要从 Kaggle 原始数据重建 cleaned/ 时才用
  ×  Olist.sql（151 MB）          仅当你想跳过清洗直接灌数据时，用它替代 ①，之后仍要跑 ②


----------------------------------------------------------------
五、新电脑最常见的 3 个报错
----------------------------------------------------------------
1) Access denied for user 'root'@'localhost'
   原因：本机 MySQL 密码不是默认的 root。
   处理：不用改代码，脚本会提示“请输入 MySQL 密码”，直接输入本机密码即可；
         也可以先设置环境变量 MYSQL_PASSWORD=你的密码。

2) Can't connect to MySQL server on 'localhost'
   原因：MySQL 服务没启动。
   处理：macOS 用 brew services start mysql，或“系统设置 -> MySQL -> Start”；
         Windows 在“服务”里启动 MySQL80。

3) ModuleNotFoundError: No module named 'fastapi'
   原因：依赖没装，或装到了另一个 Python 版本。
   处理：用 python3 -m pip install -r requirements.txt 再试；
         启动后端.py 会直接打印出该执行的 pip 命令。
