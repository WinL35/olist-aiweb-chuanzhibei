## 四、怎么重新生成技术文档 PDF

改了 `文档/技术文档.md` 后，两步重出 PDF（无需 LaTeX）：

```bash
# 1) Markdown → HTML（带打印样式与目录）
pandoc "文档/技术文档.md" -o "_技术文档.html" --standalone --toc --toc-depth=2 \
       --css "文档/_print.css" --metadata lang=zh-CN

# 2) HTML → PDF（用系统 Edge 的 printToPDF，中文由系统字体渲染）
#    等价于浏览器里 Ctrl+P → 目标「另存为 PDF」→ 边距「无」→ 勾选「背景图形」
```

> 当前 PDF 为 14 页 / 1.07 MB，满足官方「不超过 30 页」要求。
